## Summary

| Command | Writes | Plan Mode |
|---|---|---|
| `/sdd:doctor [check\|init]` | `specs/` base files (init only) | no |
| `/sdd:constitution` | `specs/constitution.md` | no |
| `/sdd:spec <type> <description>` | branch, `spec.md` | no |
| `/sdd:clarify` | `spec.md` | **never** (it writes) |
| `/sdd:plan` | `plan.md` | **recommended** |
| `/sdd:tasks` | `tasks.md`, commit | no |
| `/sdd:implement <task-id \| all>` | task commits, statuses | no |
| `/sdd:review` | `review.md`, commit, PR | no |
| `/sdd:retro` | constitution §5 | no |
| `/sdd:capabilities` | `capabilities.yml` | no |
| `/sdd:analyze` | nothing | no |
