---
title: /sdd:constitution
description: Edit the long-form project constitution.
---

Edits `specs/constitution.md`, the long-form source of truth (no token limit): tech stack, per-project commands (§2), conventions, **WHAT NOT TO DO** rules (§5) with a rationale each, testing philosophy and coverage targets (§6), out-of-scope.

It is the only file this command modifies. When the file is missing, the command directs you to `/sdd:doctor init`, which bootstraps it from the bundled template.
