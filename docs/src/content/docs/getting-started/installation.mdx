## Prerequisites

| Requirement | Why |
|---|---|
| [Claude Code](https://claude.com/claude-code) **2.1.287+** | First version with mods. `sdd` registers the `doctor_check` tool as a mod. |
| **Git** | Every feature lives on its own branch. |
| [GitHub CLI](https://cli.github.com/) (`gh`), authenticated | `/sdd:review` opens the PR with it when no `pr` action is configured. |

<Aside type="caution">
In WSL or under `--safe-mode` mods do not run, and `/sdd:doctor` falls back to a manual check.
</Aside>

## Install the plugin

Once per machine.

<Steps>

1. Add the marketplace and install:

   <Tabs>
     <TabItem label="Claude Code">
       ```text
       /plugin marketplace add JanSzewczyk/spec-driven-development
       /plugin install sdd@spec-driven-development
       ```
     </TabItem>
     <TabItem label="Shell">
       ```bash
       claude plugin marketplace add JanSzewczyk/spec-driven-development
       claude plugin install sdd@spec-driven-development
       ```
     </TabItem>
   </Tabs>

2. Enable it in `~/.claude/settings.json`:

   ```json
   {
     "enabledPlugins": {
       "sdd@spec-driven-development": true
     }
   }
   ```

3. Verify:

   ```bash
   claude plugin list | grep sdd
   ```

</Steps>

The 11 skills, 3 agents and the `doctor_check` tool are now available in **every** project. Nothing is copied per project.

## Install sdd-board (optional)

```text
/plugin install sdd-board@spec-driven-development
/sdd-dashboard
```

It declares `sdd` as a dependency, so installing it installs `sdd` too. See [sdd-board](/spec-driven-development/board/overview/).

## Fork for your organization

For a customized copy with your own defaults:

<Steps>

1. Fork the repository and update `homepage` in `plugins/sdd/.claude-plugin/plugin.json`.
2. *(Optional)* Edit `plugins/sdd/skills/doctor/templates/capabilities.yml.template` to pre-set the implementation flow.
3. *(Optional)* Edit `plugins/sdd/skills/doctor/templates/constitution.md.template` to seed your standard WHAT NOT TO DO rules.
4. Bump `version` in `plugin.json` and in the `sdd` entry of `.claude-plugin/marketplace.json`. On merge to `main`, the release workflow tags `v<version>` and creates a GitHub Release.
5. Users add your fork with `/plugin marketplace add <your-org>/<your-repo>` and install `sdd@spec-driven-development`.

</Steps>
