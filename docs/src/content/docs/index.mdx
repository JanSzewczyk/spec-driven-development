## One flow, from setup to review

<p class="landing-lead">Set up once, then every feature runs the same loop. Each command writes a file under <code>specs/</code> and re-reads its inputs from disk. Clear the chat between phases and lose nothing.</p>

<div class="why-intro">

## Why SDD

<p class="landing-lead">The spec is the source of truth, code is its consequence.</p>

</div>

<div class="why">

<div>

### Plan before code

Claude drafts the plan in Plan Mode and you approve it before a single line is written. The cheapest moment to fix a wrong turn.

</div>

<div>

### Bring your own implementer

`/sdd:implement` hands each task to a skill, agent or command you configure, or builds it in the session. The framework manages the thinking, not the typing.

</div>

<div>

### Verified against the spec

Tests, `spec-verifier` and your own checks run in parallel; `reviewer` returns **READY** or **NOT READY** and ticks the acceptance criteria.

</div>

<div>

### Any layout, any stack

Single app, monorepo or several repositories. Web, backend and mobile projects side by side. No fixed list of stacks.

</div>

</div>

</div>

## Start in two minutes

<ol class="start-steps">
  <li><strong>Install</strong> the plugin from the marketplace.</li>
  <li><strong>Initialize</strong> your project with <code>/sdd:doctor init</code>.</li>
  <li><strong>Fill in the constitution</strong> with <code>/sdd:constitution</code>: stack and rules.</li>
  <li><strong>Run the flow</strong> on your first feature.</li>
</ol>

</div>

<div class="start-code">

<Tabs>
  <TabItem label="Claude Code">
    ```text
    /plugin marketplace add JanSzewczyk/spec-driven-development
    /plugin install sdd@spec-driven-development
    ```
  </TabItem>
  <TabItem label="Shell">
    ```bash
    claude plugin marketplace add JanSzewczyk/spec-driven-development
    claude plugin install sdd@spec-driven-development
    ```
  </TabItem>
</Tabs>

Then, in your project:

```text title="claude"
/sdd:doctor init
/sdd:constitution
/sdd:spec feat user can reset password via email
/sdd:clarify
/sdd:plan
/sdd:tasks
/sdd:implement all
/sdd:review
```

</div>
