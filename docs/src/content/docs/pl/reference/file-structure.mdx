## W Twoim projekcie

Tylko artefakty per projekt. Komendy, agenci i skille weryfikacji żyją w zainstalowanym pluginie.

<FileTree>
- specs/
  - constitution.md źródło prawdy, edytowane przez /sdd:constitution
  - template.md baza dla nowych specyfikacji funkcji
  - capabilities.yml projects (init) + flows, actions, review, generated (Twoje)
  - **&lt;feature-slug&gt;/**
    - spec.md specyfikacja biznesowa
    - plan.md decyzje, kontrakty, zmiany plik po pliku
    - tasks.md samodzielne zadania pod jednym Epikiem
    - review.md zapisywany przez /sdd:review
- .claude/
- CLAUDE.md opcjonalny, Twój, nigdy nietykany przez SDD
</FileTree>

<Aside type="note">
SDD tworzy lub edytuje tylko `specs/constitution.md`, `specs/template.md`, `specs/capabilities.yml` oraz, przy sąsiednich repozytoriach, `permissions.additionalDirectories` w `.claude/settings.json`. Cała reszta, w tym główny `CLAUDE.md`, jest Twoja.
</Aside>
