## Jeden przepływ, od konfiguracji do review

<p class="landing-lead">Konfigurację robisz raz, potem każda funkcja przechodzi tę samą pętlę. Każda komenda zapisuje plik w <code>specs/</code> i odczytuje wejście z dysku. Możesz czyścić czat między fazami i nic nie tracisz.</p>

<div class="why-intro">

## Dlaczego SDD

<p class="landing-lead">Specyfikacja jest źródłem prawdy, kod jest jej konsekwencją.</p>

</div>

<div class="why">

<div>

### Plan przed kodem

Claude przygotowuje plan w Plan Mode, a Ty go zatwierdzasz, zanim powstanie jakakolwiek linia kodu. To najtańszy moment na poprawienie złego kierunku.

</div>

<div>

### Własny implementator

`/sdd:implement` przekazuje każde zadanie do skilla, agenta lub komendy, które skonfigurujesz, albo buduje je w sesji. Framework zarządza myśleniem, nie pisaniem.

</div>

<div>

### Weryfikacja względem specu

Testy, `spec-verifier` i Twoje własne sprawdzenia działają równolegle; `reviewer` zwraca **READY** lub **NOT READY** i odhacza kryteria akceptacji.

</div>

<div>

### Dowolny układ, dowolny stack

Jedna aplikacja, monorepo lub kilka repozytoriów. Projekty webowe, backendowe i mobilne obok siebie. Bez ustalonej listy stacków.

</div>

</div>

</div>

## Start w dwie minuty

<ol class="start-steps">
  <li><strong>Zainstaluj</strong> plugin z marketplace.</li>
  <li><strong>Zainicjuj</strong> projekt komendą <code>/sdd:doctor init</code>.</li>
  <li><strong>Uzupełnij konstytucję</strong> komendą <code>/sdd:constitution</code>: stack i reguły.</li>
  <li><strong>Uruchom przepływ</strong> na pierwszej funkcji.</li>
</ol>

</div>

<div class="start-code">

<Tabs>
  <TabItem label="Claude Code">
    ```text
    /plugin marketplace add JanSzewczyk/spec-driven-development
    /plugin install sdd@spec-driven-development
    ```
  </TabItem>
  <TabItem label="Shell">
    ```bash
    claude plugin marketplace add JanSzewczyk/spec-driven-development
    claude plugin install sdd@spec-driven-development
    ```
  </TabItem>
</Tabs>

Następnie w swoim projekcie:

```text title="claude"
/sdd:doctor init
/sdd:constitution
/sdd:spec feat user can reset password via email
/sdd:clarify
/sdd:plan
/sdd:tasks
/sdd:implement all
/sdd:review
```

</div>
