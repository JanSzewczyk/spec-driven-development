```text
/sdd:implement T2        # one task
/sdd:implement all       # every ready task
```

A **dispatcher**, not an implementer. It checks `depends_on`, builds the brief, hands the task to the flow configured in [`capabilities.yml`](/spec-driven-development/2.0/configuration/capabilities/) (`skill:`, `agent:`, `command:` or `in-session`) and tracks the status.

| Behavior | Detail |
|---|---|
| Parallelism | Independent tasks may go to a background flow together; otherwise one after another. |
| Sibling repos | Makes sure the feature branch exists in that repository first. |
| Verification | Runs **no tests itself**: the implementer does, and [`/sdd:review`](/spec-driven-development/2.0/commands/review/) verifies. |
| Commits | Commits any documentation `/sdd:tasks` left uncommitted before the first task, then each finished task's files with a `Task: <EPIC>-T<n>` trailer. |
| Isolation | With `isolation: worktree:` it orchestrates sub-sessions instead. See [Isolated tasks](/spec-driven-development/2.0/concepts/isolation/). |

<Aside type="tip">
  Open a fresh session per task. `tasks.md` status is the handover document, so nothing is lost.
</Aside>
